    기존 출력 PDF를 추가하면
    세 가지 결과를 나란히 봅니다.

    페이지 번호 기준 비교입니다. 페이지가 달라진 기존 출력의 내용은 자동 정렬되지 않습니다.

    레이아웃 설정 · 비교 PDF 직접 추가

    원본 폰트와 문자별 위치로 다시 그려 복원 정확도를 확인합니다.

    같은 원문과 위치가 반복되는 머리말에 적용합니다. 직접 수정한 영역은 번역 통일에서 제외합니다.

    API 번역 비교 시 자동 생성됩니다. 별도 PDF를 올리면 동일 번역문 여부는 확인할 수 없습니다.

    원문 재삽입은 위치 복원 검사에, FIT는 번역문·수동 교체문 배치에 사용합니다. 엔터와 들여쓰기는 FIT에 반영됩니다.

    영역 살펴보기 —
    영역을 선택하면 원문·폰트·교체 텍스트를 확인할 수 있습니다.

    번역 묶음 · 원본 영역 연결

    번역 상태와 PDF 배치 상태를 따로 확인합니다.

    묶음 변경 시 해당 번역만 대기로 돌아갑니다. 아래 ‘이 영역만 다시 번역·적용’을 누르거나 교체문을 입력하세요. 원본 좌표는 보존됩니다.

    영역 합치기 · 박스 조절

    단위: pt

    박스는 번역문을 배치할 공간입니다. 원문을 지우는 범위는 늘어나지 않습니다. 저장 전에는 PDF가 바뀌지 않습니다.

    영역을 선택하면 PDF 반영 여부를 표시합니다.

    선택한 영역만 재배치합니다. 원문과 번역문은 별도로 보관되며, 원문 복원 후에도 번역문을 다시 적용할 수 있습니다.

    여러 영역 선택 · 0개 선택

    교체문을 확인한 영역을 체크하세요. 다른 페이지로 이동해도 선택은 유지됩니다. 선택한 영역만 한 번에 적용합니다.

    사용자 검토

    현재 실행의 선택 영역에 기록합니다. 확인 완료로 표시해도 PDF는 변경되지 않습니다.

    설정

    새 작업의 기본값과 PDF 비교 환경을 설정합니다.

    번역 연결

    서버 설정 확인 중…

    API 설정은 서버의 .env를 사용합니다. 키는 이 화면이나 브라우저 저장소에 저장하지 않습니다.

    작업 기본값

    이 브라우저에 저장됩니다. 새 문서에는 언어·실행 기본값을 적용하고, 저장된 문서에는 해당 작업의 언어를 사용합니다.

    출력과 검토 범위

    PDF가 기본 출력입니다. 편집 가능한 DOCX와 검증된 추가 형식만 Export에 표시됩니다. 사용자 검토·수정 기록과 이전 실행 파일은 Lab 데이터 폴더에 저장됩니다.

    회전 글자, 사진 배경, 작은 글자와 체크란은 자동 검사 후에도 원본과 비교해 주세요. 자동 검사 통과는 번역 의미의 정확성을 보증하지 않습니다.
